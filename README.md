AI Chatbot – Software Engineering Assignment
Overview
This assignment presents a software requirements analysis for an AI-powered Chatbot system. It covers users, purpose, stakeholders, functional and non-functional requirements, risks, quality attributes, and the role of AI in the system.
A. Users
Students
Employees
Customer Service Representatives
General Users
B. Purpose
The chatbot communicates with users through natural language. It can:
Answer questions
Guide users through tasks or information
C. Stakeholders
Stakeholder
Role
Users
Receive information and assistance from the chatbot
Business
Uses the chatbot to improve service quality
Developers
Develop, maintain, monitor, and update the chatbot
D. Functional Requirements
The chatbot shall accept user questions in natural language.
It should provide relevant responses.
It should analyze and maintain conversation context.
It should store all chat data.
E. Non-Functional Requirements
Performance: Should respond within a few seconds.
Privacy: User personal information should be protected.
Usability: Interface should be simple and user-friendly.
F. Risks
May provide inaccurate information.
User information could be exposed (data breach risk).
G. Quality Attributes
Reliability – The system should consistently perform correctly.
Usability – Easy to use for all types of users.
Security – Protects user data and prevents unauthorized access.
H. Where AI Could Be Used
AI could be used to:
Understand natural language (NLP)
Generate human-like responses
Summarize long conversations
I. What Could Go Wrong if AI Is Used Incorrectly
Misinformation – AI may generate false or misleading answers.
Bias – AI responses may reflect training data biases.
Privacy Violations – Sensitive user data may be mishandled.
